# CargoFlow Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A branded, responsive, fully working Next.js 16 frontend for CargoFlow, with the small backend
additions the browser needs, verified by Playwright against the real local stack.

**Architecture:** `frontend/` is a Next.js 16 App Router app. It reads the Go API (REST + WebSocket) through
typed, zod-validated hooks, and writes to the chain from the user's wallet via wagmi/viem. Three backend
additions are public and safe: shipment mirroring that the chain must confirm, stats, and a telemetry summary
of aggregates only. Demo endpoints exist behind `DEMO_MODE`. Judge mode reuses the same hero-runner code as
the CLI and the tests.

**Tech Stack:** Next.js 16.3, React 19.3, TypeScript 5.9 (strict), Tailwind CSS 4.3, wagmi 3.7 + viem 2.57,
TanStack Query 5, zod 4, Vitest 5 + Testing Library, Playwright 1.63 + @axe-core/playwright, pnpm. Backend:
Go 1.24, existing packages.

**Spec:** [`docs/superpowers/specs/2026-10-02-frontend-design.md`](../specs/2026-10-02-frontend-design.md)

## Global Constraints

- Next.js **16** (App Router, React 19, Turbopack). TypeScript `strict: true`. No `any` in `src/lib`.
- Tokens are exactly: ink `#0B1B2B`, ink-2 `#13293D`, paper `#F7F9F4`, signal `#C6F432`, signal-ink `#0B1B2B`,
  verified `#00C46A`, alert `#FFB020`, danger `#E5484D`, slate `#5B6B7B`, line `#DCE3DA`.
- Fonts: Space Grotesk (display), Inter (body), JetBrains Mono (hashes, amounts, ids) via `next/font/google`.
- Breakpoints verified: 375, 768, 1280 px; no horizontal page scroll at 375.
- USDG has 6 decimals; amounts travel as decimal strings of base units and are formatted, never converted to
  floating point for arithmetic.
- Chain ids: 46630 (Robinhood Chain Testnet), 31337 (local anvil). Explorer:
  `https://explorer.testnet.chain.robinhood.com`.
- WalletConnect project id comes from `NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID`. The API base URL comes from
  `NEXT_PUBLIC_API_URL` (default `http://127.0.0.1:8080`).
- The browser never holds an admin key or a private key. Demo wallets live only in the backend, behind
  `DEMO_MODE=true`.
- Raw readings and salts never leave the backend. The telemetry summary returns aggregates only.
- Every commit is one line with no co-author trailer (user rule). Commit after every task.
- Respect `prefers-reduced-motion`. No serious or critical axe violations.

## Review Focus

1. **Wrong network or no wallet when a role action is clicked.** Expect a clear "switch to Robinhood Chain
   Testnet" or "connect wallet" prompt, never a silent failure. (Task F6 test: `useTx` refuses and reports
   on a wrong chain.)
2. **An unknown shipment id or reference typed into the track bar.** Expect a friendly not-found state with a
   path back, not a crash. (Task F9 e2e: `/track/0xdead…` shows "We couldn't find that shipment".)
3. **The backend is down or returns an unexpected shape.** Expect an offline banner and a retry button; zod
   parse errors are shown as errors. (Task F5 test: a parser rejects a malformed view; Task F14 e2e with the
   API stopped.)
4. **Double-clicking a transaction button.** Expect only one transaction sent. (Task F6 test: a second
   `send()` while pending is a no-op.)
5. **A demo scene clicked twice, or out of order.** Expect the recorded result to be returned, not a duplicate
   chain action; out of order gives a 409 with the next allowed scene. (Task B5 tests.)

```go
package store

import "context"

// Stats are platform-wide counts for the public landing page.
type Stats struct {
	Shipments       map[string]int `json:"shipments"`
	Total           int            `json:"total"`
	EpochsCommitted int            `json:"epochsCommitted"`
	ProofsVerified  int            `json:"proofsVerified"`
}

// Stats counts shipments by status and committed, proof-verified epochs.
func (s *Store) Stats(ctx context.Context) (Stats, error) {
	st := Stats{Shipments: map[string]int{}}
	rows, err := s.pool.Query(ctx, "SELECT status, count(*) FROM shipments GROUP BY status")
	if err != nil {
		return st, err
	}
	for rows.Next() {
		var status string
		var n int
		if err := rows.Scan(&status, &n); err != nil {
			rows.Close()
			return st, err
		}
		st.Shipments[status] = n
		st.Total += n
	}
	rows.Close()
	err = s.pool.QueryRow(ctx, `SELECT count(*) FILTER (WHERE commit_tx_hash IS NOT NULL),
		count(*) FILTER (WHERE proof_verified) FROM telemetry_epochs`).Scan(&st.EpochsCommitted, &st.ProofsVerified)
	return st, err
}
```

```go
func clientIP(r *http.Request) string {
	host, _, err := net.SplitHostPort(r.RemoteAddr)
	if err != nil {
		return r.RemoteAddr
	}
	return host

func (s *Server) mirror(w http.ResponseWriter, r *http.Request) error {
	if err := s.rateLimit(w, "mirror:"+clientIP(r), s.c.MirrorPerMinute); err != nil {
		return err

		return nil

	sh, err := s.c.Service.RegisterShipment(r.Context(), req.input())
	if err != nil {
		return err
	}
	writeJSON(w, http.StatusCreated, sh)
	return nil
}
```

```go
// Scene names, in the only order they may run.
const (
	SceneSetup     = "setup"     // register, policy, facility, fund, start transit, register with backend
	SceneHealthy   = "healthy"   // 16 readings: two milestones release
	SceneExcursion = "excursion" // 8 readings: anomaly, pause
	SceneRecover   = "recover"   // 8 core-probe readings + ZK proof -> resume
	SceneFinish    = "finish"    // 16 readings: milestones 4 and 5
	SceneSettle    = "settle"    // markDelivered, approve, settle
)
var Scenes = []string{SceneSetup, SceneHealthy, SceneExcursion, SceneRecover, SceneFinish, SceneSettle}

type Session struct { /* runner state: id, ref, t0, source key, step index, results */ }
func NewSession(cfg Config) (*Session, error)            // validates cfg like Run
func (s *Session) Run(ctx context.Context, scene string) (StepResult, error)
func (s *Session) ShipmentID() string
func (s *Session) Done() []string                        // completed scenes in order
type StepResult struct {
	Scene     string   `json:"scene"`
	TxHashes  []string `json:"txHashes"`
	Status    string   `json:"status"`    // facility status after the scene
	Drawn     string   `json:"drawn"`     // base units
}
var ErrOutOfOrder = errors.New("hero: scene out of order")
```

  `Run(ctx, scene)` behaves as follows:
  - A scene that has already completed returns its stored `StepResult` (idempotent).
  - A scene that isn't next returns `ErrOutOfOrder` wrapped with the next scene's name.
  - `hero.Run(ctx, cfg)` becomes: create a `Session`, run every scene in order, then compute `Result` as today.

```ts
const SCALE = 10n ** 6n;
const group = (s: string) => s.replace(/\B(?=(\d{3})+(?!\d))/g, ",");

export function formatUSDG(v: string | bigint, opts: { compact?: boolean } = {}): string {
  const n = typeof v === "bigint" ? v : BigInt(v || "0");
  const neg = n < 0n;
  const abs = neg ? -n : n;
  const sign = neg ? "-" : "";
  if (opts.compact && abs >= 1000n * SCALE) {
    // pick the largest unit the value reaches, then show one truncated decimal
    const units: [string, bigint][] = [["B", 10n ** 9n], ["M", 10n ** 6n], ["K", 10n ** 3n]];
    const [label, size] = units.find(([, u]) => abs >= u * SCALE)!;
    const tenths = (abs * 10n) / (size * SCALE);
    const whole = tenths / 10n, tenth = tenths % 10n;
    return `${sign}${whole}${tenth ? "." + tenth : ""}${label}`;
  }
  const whole = abs / SCALE;
  const frac = (abs % SCALE).toString().padStart(6, "0").replace(/0+$/, "");
  return `${sign}${group(whole.toString())}${frac ? "." + frac : ""}`;
}
export const formatBps = (bps: number) => `${(bps / 100).toFixed(1)}%`;
export const formatTempX100 = (v: number) => `${(v / 100).toFixed(1)} °C`;
export const shortHash = (hex: string, head = 6, tail = 4) =>
  hex.length <= 2 + head + tail ? hex : `${hex.slice(0, 2 + head)}…${hex.slice(-tail)}`;
```
