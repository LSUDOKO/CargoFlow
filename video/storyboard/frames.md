# CargoFlow v2 storyboard: key frames

Companion to `video/SCRIPT-v2.md` (timings, VO and direction live there; this file is what each thumbnail looks
like). Frame numbers are absolute at 30 fps. Each entry is one storyboard panel: **composition** (what is where, in a
1920 x 1080 frame), **motion into the next panel**, and **why it moves**. Grid references: x left→right, y top→bottom;
"desk line" is y = 860.

Legend for colour words: lime = `#C6F432`, emerald = `#00C46A`, amber = `#FFB020`, red = `#E5484D`, ink = `#0B1B2B`,
paper = `#F7F9F4`.
